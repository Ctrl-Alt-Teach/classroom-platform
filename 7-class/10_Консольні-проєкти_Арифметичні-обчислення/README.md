# Урок №10 — Консольні проєкти з простими арифметичними обчисленнями

**Клас:** 7  
**Навчальна гра:** CODE QUEST 7 — Python Challenge  
**Файл:** `index.html`  
**Публічна версія для учнів:** https://irishka464642.github.io/informatics-lab/python-quest-7/

## Призначення

Інтерактивний мобільний тренажер для закріплення змінних, присвоювання, арифметичних операторів `+`, `-`, `*`, `/`, введення `input()`, перетворення типів `int()` / `float()` та виведення `print()`.

Учні збирають фрагменти коду за допомогою сенсорних кнопок (серед яких є зайві варіанти) або вводять код вручну. Редактор на початку місії порожній.

## Структура гри

**Етап 1 — тренування (5 місій):**
1. Ресурси бази — змінні та присвоювання.
2. Апгрейд інвентарю — додавання.
3. Магазин апгрейдів — множення.
4. Термінал доступу — `input()` і `int()`.
5. Підсумок раунду — `print()` і додавання.

**Етап 2 — челендж (4 місії):**
6. Планування бази — периметр прямокутника.
7. Розрахунок знижки — обчислення вартості покупки.
8. Кодовий сейф — обчислення математичного виразу.
9. Фінал: калькулятор — введення двох чисел та чотири арифметичні дії.

## Проведення уроку

1. Запропонуйте учням відкрити публічне посилання на смартфонах.
2. На старті учні обирають клас **7-А / 7-Б / 7-В**, групу **1 / 2**, уводять прізвище й ім’я.
3. Перші п’ять місій можна виконувати разом із поясненнями вчителя.
4. Наступні чотири місії — самостійна робота; підказки з’являються після невдалої перевірки.
5. Наприкінці учень показує екран із результатом, робить скриншот або копіює підсумок.
