## Проміжні збереження (оновлення 17.11.2026)

**Гра автоматично формує повні знімки до журналу після переходу з 5-го, 6-го, 7-го, 8-го, 9-го та 10-го рівнів.** Після успішного запуску на відповідному рівні потрібно натиснути кнопку «Зберегти та перейти» (у фіналі — «Зберегти результат»). Перевір усі варіанти тестових даних **перед** натисканням цієї кнопки.

Кожен знімок має власний `submissionId`, наприклад:
`cq7-<сеанс>-L05`, `cq7-<сеанс>-L06`, ... `cq7-<сеанс>-L10`.
Повторне надсилання того самого рубежу використовує незмінний ID і має відсікатися на стороні Apps Script; повторний запуск з іншими тестовими даними після знімка в цьому рубежі не перезаписує вже зроблений знімок.

**Важливо для аналітики:** знімки *накопичувальні*. Тому на вкладках «Результати», «Рівні» та «Запуски тестів» буде історія з кількома знімками одного сеансу. **Не підсумовувати сирі рядки різних знімків!** Для аналізу одного сеансу використовувати **останній досягнутий рубіж** за суфіксом `-L05`…`-L10`. Останній знімок уже містить усі попередні рівні та запуски.

Відправлення виконується методом `POST` у `no-cors` і має `keepalive: true`. Браузер не отримує технічного підтвердження успішного запису. У грі доступна кнопка повторної відправки останнього рубежу. Втрата мережі або непублічні права Apps Script можуть перешкодити запису; вчителю потрібно перевірити надходження рядків у Google Таблицю.

**Автозбереження прогресу в браузері та продовження гри на іншому пристрої поки немає.** Це автозбереження *навчальних результатів у шкільну таблицю*, не можливість відновити незавершену гру.
