# Уроки № 67-68

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 67:** Практикум з використання інформаційних технологій. Етапи виконання проєкту. Складання плану, визначення завдань і вибір засобів.
- **Урок 68:** Комплексний колективний проєкт: пошук, аналіз та опрацювання матеріалів, створення інформаційних продуктів.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
