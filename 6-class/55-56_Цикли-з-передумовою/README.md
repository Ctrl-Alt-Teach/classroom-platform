# Уроки № 55-56: Цикли з передумовою

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 55:** Алгоритми і програми з циклами з передумовою.
- **Урок 56:** Практичні вправи з циклами з передумовою.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
