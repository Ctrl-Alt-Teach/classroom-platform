# Уроки № 51-52: Вкладені розгалуження

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 51:** Алгоритми і програми з вкладеними розгалуженнями.
- **Урок 52:** Практичні вправи з вкладеними розгалуженнями. Редагування алгоритмів.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
