# Уроки № 27-28: Векторні зображення та шари

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік  
**Дата:** 14.12.2026

## Теми за КТП

- **Урок 27:** Створення, редагування і форматування векторних зображень.
- **Урок 28:** Шари, їх використання. Практичні вправи з векторними графічними об’єктами, розміщеними в різних шарах.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
