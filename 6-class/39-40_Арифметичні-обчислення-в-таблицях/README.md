# Уроки № 39-40: Арифметичні обчислення в таблицях

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 39:** Арифметичні обчислення в електронних таблицях.
- **Урок 40:** Практичні вправи з арифметичними обчисленнями в електронних таблицях.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
