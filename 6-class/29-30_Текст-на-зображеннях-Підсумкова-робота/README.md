# Уроки № 29-30: Текст на зображеннях Підсумкова робота

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік  
**Дата:** 21.12.2026

## Теми за КТП

- **Урок 29:** Додавання тексту до графічних зображень та його форматування.
- **Урок 30:** Творча підсумкова робота з комп’ютерної графіки. Представлення результатів. Підсумкове оцінювання за групами загальних результатів за І семестр.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
