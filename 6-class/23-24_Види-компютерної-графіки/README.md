# Уроки № 23-24: Види компютерної графіки

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік  
**Дата:** 30.11.2026

## Теми за КТП

- **Урок 23:** Базові поняття комп’ютерної графіки. Види комп’ютерної графіки.
- **Урок 24:** Програми для опрацювання графічних зображень. Порівняння властивостей графічних зображень різних видів.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
