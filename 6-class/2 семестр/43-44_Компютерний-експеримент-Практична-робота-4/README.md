# Уроки № 43-44: Компютерний експеримент Практична робота 4

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 43:** Комп’ютерний експеримент. Опрацювання результатів експерименту з використанням електронних таблиць і діаграм.
- **Урок 44:** Практична робота № 4 «Створення електронних таблиць. Обчислення в електронних таблицях. Побудова діаграм».

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
