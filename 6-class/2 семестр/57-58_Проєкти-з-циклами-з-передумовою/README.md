# Уроки № 57-58

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 57:** Проєкти з циклами з передумовою.
- **Урок 58:** Тестування та налагодження проєктів із циклами з передумовою.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
