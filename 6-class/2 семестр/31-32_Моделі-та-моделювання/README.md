# Уроки № 31-32: Моделі та моделювання

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 31:** Поняття моделі. Види моделей. Інформаційні моделі. Математичні моделі.
- **Урок 32:** Створення інформаційних і математичних моделей. Визначення істотних властивостей об’єктів та їх значень.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
