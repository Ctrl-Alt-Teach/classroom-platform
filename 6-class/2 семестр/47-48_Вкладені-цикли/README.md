# Уроки № 47-48: Вкладені цикли

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 47:** Алгоритми і програми з вкладеними циклами.
- **Урок 48:** Практичні вправи з вкладеними циклами. Обґрунтування вибору алгоритмічних структур.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
