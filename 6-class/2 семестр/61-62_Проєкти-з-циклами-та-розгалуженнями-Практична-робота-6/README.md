# Уроки № 61-62

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 61:** Проєкти з вкладеними циклами і розгалуженнями. Підготовчі практичні вправи.
- **Урок 62:** Практична робота № 6 «Проєкти з вкладеними циклами і розгалуженнями».

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
