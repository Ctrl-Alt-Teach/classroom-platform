# Уроки № 69-70

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 69:** Подання та оцінювання результатів комплексного проєкту. Підсумкове оцінювання за групами загальних результатів за ІІ семестр.
- **Урок 70:** Повторення та узагальнення вивченого. Самооцінювання та рефлексія щодо досягнутих результатів навчання.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
