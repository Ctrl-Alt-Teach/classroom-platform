# Уроки № 59-60

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 59:** Алгоритми і програми з вкладеними циклами і розгалуженнями.
- **Урок 60:** Практичні вправи з поєднання вкладених циклів і розгалужень.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
