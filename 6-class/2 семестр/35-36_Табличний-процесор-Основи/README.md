# Уроки № 35-36: Табличний процесор Основи

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 35:** Табличний процесор. Призначення та основні об’єкти електронної таблиці.
- **Урок 36:** Практичні вправи в табличному процесорі: введення, редагування та організація даних.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
