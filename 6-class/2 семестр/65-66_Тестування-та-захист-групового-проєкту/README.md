# Уроки № 65-66

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 65:** Тестування та налагодження групового проєкту з вкладеними циклами і розгалуженнями.
- **Урок 66:** Представлення результатів проєкту. Аналіз роботи групи та внеску кожного учасника.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
