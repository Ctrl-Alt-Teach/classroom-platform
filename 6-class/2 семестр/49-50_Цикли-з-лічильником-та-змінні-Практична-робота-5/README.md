# Уроки № 49-50: Цикли з лічильником та змінні Практична робота 5

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 49:** Алгоритми і програми з вкладеними циклами з лічильником та зі змінними.
- **Урок 50:** Практична робота № 5 «Проєкти з вкладеними циклами з лічильником та зі змінними».

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
