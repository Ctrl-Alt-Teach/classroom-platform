# Уроки № 45-46: Змінні та лінійні алгоритми

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 45:** Величини. Команда присвоювання. Лінійні алгоритми зі змінними.
- **Урок 46:** Практичні вправи зі складання, виконання та редагування лінійних алгоритмів зі змінними.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
