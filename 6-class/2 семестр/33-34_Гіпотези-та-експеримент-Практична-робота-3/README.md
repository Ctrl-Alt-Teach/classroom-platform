# Уроки № 33-34: Гіпотези та експеримент Практична робота 3

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 33:** Гіпотеза. Перевірка гіпотези з використанням моделі. Експеримент. Добір даних для перевірки гіпотез.
- **Урок 34:** Практична робота № 3 «Проведення дослідження з використанням моделі».

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
