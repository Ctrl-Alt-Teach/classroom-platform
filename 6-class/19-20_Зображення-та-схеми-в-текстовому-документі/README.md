# Уроки № 19–20: Зображення та схеми в текстовому документі

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік  
**Дата:** 16.11.2026

## Теми за КТП

- **Урок 19:** Зображення в текстовому документі.
- **Урок 20:** Схеми в текстовому документі. Вставлення та опрацювання графічних об’єктів. Практичні вправи.

## Інтерактивний зошит для індивідуальної роботи

**[Відкрити код навчального сайту](./index.html)**

Учні працюють **індивідуально** зі смартфонів. Один сайт має три вкладки:

- **Редактор** — написання й форматування тексту, вставлення та масштабування зображень, розташування та обтікання текстом, створення послідовних схем із прямокутників, овалів, ромбів і стрілок; додатково — проста таблиця.
- **Завдання** — 6 послідовних індивідуальних місій, по 3 на кожен урок, із відмітками виконання.
- **Довідка** — короткі алгоритми дій і пояснення значення фігур та обтікання.

**Урок 19:** мій короткий текст, вставлення ілюстрації, зміна розміру та дослідження обтікання.

**Урок 20:** послідовна схема ранкових дій, редагування фігур і написів, фінальний документ із текстом, ілюстрацією та схемою.

Сайт складається з `index.html`, `style.css` та `app.js`. Він працює без зовнішніх JS-бібліотек. Поточний документ і відмітки виконання зберігаються локально у браузері, а документ можна завантажити як HTML-файл або передати через системне меню поширення, якщо браузер підтримує передачу файлів.

> **Для вчителя.** Посилання на `index.html` у GitHub відкриває код файлу, а не інтерактивний редактор. Для роботи учнів потрібна публікація через GitHub Pages або інший статичний хостинг. Папка сайту вже знаходиться всередині чинного репозиторію `Ctrl-Alt-Teach/classroom-platform`. Усі файли цього зошита мають лежати разом у цій папці.
