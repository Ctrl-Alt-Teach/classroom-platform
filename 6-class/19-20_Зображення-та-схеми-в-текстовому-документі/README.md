# Уроки № 19-20: Зображення та схеми в текстовому документі

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік  
**Дата:** 16.11.2026

## Теми за КТП

- **Урок 19:** Зображення в текстовому документі.
- **Урок 20:** Схеми в текстовому документі. Вставлення та опрацювання графічних об’єктів. Практичні вправи.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.

## Онлайн-симулятор текстового редактора

**[Відкрити навчальний редактор Word](./index.html)** — адаптований для смартфонів редактор для практичних завдань з уроків № 19–20.

Можливості: введення й форматування тексту, вставлення зображень із телефону, зміна їхніх розмірів та розташування, обтікання текстом, вставлення таблиць, прямокутників, овалів, ромбів і стрілок. Документ автоматично зберігається в браузері цього пристрою; окремо його можна завантажити як HTML-файл.

**Урок 19.** Створення короткого тексту з ілюстрацією, зміна розмірів і розміщення зображення, перевірка обтікання текстом.

**Урок 20.** Створення простої схеми з геометричних фігур і стрілок, редагування підписів.
