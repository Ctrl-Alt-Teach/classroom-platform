# Уроки № 63-64

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 63:** Розкладання задачі на підзадачі. Планування групового проєкту з вкладеними циклами і розгалуженнями. Розподіл ролей.
- **Урок 64:** Колективна робота зі створення проєкту з вкладеними циклами і розгалуженнями.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
