# Уроки № 25-26: Растрові зображення

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік  
**Дата:** 07.12.2026

## Теми за КТП

- **Урок 25:** Створення, редагування і форматування растрових зображень.
- **Урок 26:** Практичні творчі вправи зі створення та опрацювання растрових зображень.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
