# Уроки № 37-38: Редагування та форматування таблиць

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 37:** Редагування електронних таблиць.
- **Урок 38:** Форматування електронних таблиць. Практичні вправи.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
