# Уроки № 53-54: Проєкти з вкладеними розгалуженнями

**Клас:** 6-В  
**КТП:** 2026/2027 навчальний рік

## Теми за КТП

- **Урок 53:** Алгоритми і програми з вкладеними розгалуженнями. Практичні вправи.
- **Урок 54:** Створення, тестування та налагодження проєктів із вкладеними розгалуженнями.

## Матеріали уроків

Сюди додаються конспект, інтерактивні вправи, презентація, картки та файли практичних робіт.
